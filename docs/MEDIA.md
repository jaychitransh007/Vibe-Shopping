# Replace the media placeholders

The published placeholders intentionally say **Screenshot placeholder** or **Video coming soon**. They are not simulated product results. Replace them after the concurrent application implementation has reached a stable, identified commit.

## Capture list

| Placeholder | Actual capture needed |
| --- | --- |
| `assets/screenshot-profile.svg` | Profile onboarding or style-analysis summary with a non-identifying demonstration profile. |
| `assets/screenshot-chat.svg` | An actual styling request, outfit carousel, and readable explanation. |
| `assets/screenshot-wardrobe.svg` | Wardrobe upload and saved garment selection, using owned or licensed garment imagery. |
| `assets/screenshot-tryon.svg` | An actual generated try-on for the same example journey. |
| `assets/screenshot-looks.svg` | Looks history with saved-look and try-on filters visible. |
| `assets/screenshot-products.svg` | Product detail, retailer name, price context, evidence indicators, and retailer action. |
| `assets/demo-video-placeholder.svg` | Poster frame linked to a captioned 60–90 second recording. |

## Recording sequence

1. Occasion and budget.
2. Real outfit suggestions and explanation.
3. One specific follow-up and the observed response.
4. Virtual try-on, if available in the demonstrated version.
5. Save or share the look and inspect a retailer product.

## Publication checks

- Record the commit, capture date, market, and whether data is illustrative or live.
- Use demonstration data and images cleared for public presentation. Exclude account identifiers and private profile information.
- Label an illustrative local preview as such. Label edited waiting time if the recording compresses it.
- Use consistent desktop captures and add a mobile capture for the gallery when available.
- Add captions and a text transcript or equivalent written walkthrough.
- Change the placeholder labels and image links only after the real media is uploaded and accessible.
- Update image paths in both this showcase and the profile README. Do not replace the source application or trigger a deployment as part of this media change.
